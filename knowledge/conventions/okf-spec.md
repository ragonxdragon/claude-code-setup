# OKF Specification

Plain markdown plus YAML frontmatter. One concept per file. No SDK or proprietary dependency.

## Frontmatter schema

```yaml
---
type: <Skill | Agent | Marketplace | Convention>   # required
title: <human-readable name>
description: <one-line summary; becomes the routing-table cell>
resource: <path to the skill dir, marketplace path, or URL>
tags: [tag1, tag2]
timestamp: <YYYY-MM-DD>
domains: [process, engineering]   # routing keys; required outside conventions/
depth: <single | rich>            # rich = the file lists sub-skills or several sections
model: <haiku | sonnet | opus>    # optional recommended tier; advisory, never auto-applied
related: [agents/custom.md]       # optional
---
```

- **Required:** `type`. Files outside `conventions/` also need `domains`, or they are invisible to routing.
- **Recommended:** `title`, `description`, `tags`, `timestamp`.
- **Optional:** `resource`, `depth`, `model`, `related`.

Lists can be inline (`[a, b]`) or YAML block lists. Valid `domains` keys are the keys of `DOMAIN_LABELS` in `scripts/build_routing.py`; add a key there to add a routing section.

## Types

| type | Use for |
| ---- | ------- |
| `Convention` | Rules, workflow patterns, templates |
| `Skill` | Skill domain concept files (not the SKILL.md itself) |
| `Agent` | Agent type concept files |
| `Marketplace` | Marketplace or plugin registry files |

## Cross-links

Use standard markdown links, `[title](relative/path.md)`, for every cross-reference inside `knowledge/`. Use `[[name]]` only as a placeholder when the target file does not exist yet, and convert it to a real link once the file exists. The link checker warns on any remaining `[[name]]` so the placeholder stays visible.

## Bundle structure

Each bundle (`conventions/`, `skills/`, `agents/`, and optionally `marketplaces/`) has:

- `index.md`: the routing file that lists every member with a one-line description. For `skills/`, `agents/`, and `marketplaces/` it is generated by `build_routing.py`.
- One `.md` file per concept or domain.

## Validation

```bash
python scripts/validate_okf.py       # every knowledge/**/*.md has a valid type
python scripts/check_links.py        # broken relative links, leftover [[name]]
python scripts/check_routing.py      # CONTEXT.md and indexes match frontmatter
python scripts/frontmatter_audit.py  # tags, domains, taxonomy, skill descriptions
python scripts/build_visualizer.py   # self-contained HTML graph of knowledge/
```
