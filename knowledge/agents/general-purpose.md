# General-Purpose Agent

**Type:** `general-purpose` (built into Claude Code)

Catch-all for research, search, and multi-step tasks that do not match a more specific agent type.

**Tools:** all tools.

**Use when** the task is broad, or no specialized agent fits. Give it a narrow ask and a required report format; a loosely scoped subagent reads far more than it needs.
